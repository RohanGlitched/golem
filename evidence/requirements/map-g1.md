# G1 stability map

The line the map in `evidence/map-g1` sweeps. The map script substitutes the push force, direction and stride phase, so only the shape of the line matters.

### Requirement 1: Survive a push

#### Acceptance Criteria

1. WHEN the pelvis is pushed with up to 400 N for 0.2 s from any direction at any point in its stride THE robot SHALL stay upright for 3 s
